How the dual-layer encryption works
  1. Upload: A random Data Encryption Key (DEK) is generated per file. The file is encrypted with AES-GCM using that DEK. The DEK is then wrapped (encrypted) with your ECC public key via ECIES and stored.
  2. Your password: A PBKDF2-SHA256 hash of your per-file password is stored. At download time it acts as the gate — the ECC unwrap only runs after the password is verified.
  3. Download: You enter your file password. The server verifies the hash, then uses your stored ECC private key to unwrap the DEK, and finally decrypts the file with AES-GCM. You never have to paste keys.
